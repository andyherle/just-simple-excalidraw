- No hover labels.
- No previews in Source mode or while editing a link.
- Light and dark themes.
- Size limits for large drawings and images.

Install `main.js`, `manifest.json`, and `styles.css` in the plugin folder.
Restart Obsidian.

Test both themes and note modes. Edit an embed link, then move the cursor away.
